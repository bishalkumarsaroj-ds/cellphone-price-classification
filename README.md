# Cellphone Price Range Classification

Classification model to predict the price range of a cellphone based on 
its specifications.

## 🎯 Objective
Classify cellphones into price range categories using specifications 
like RAM, battery power, camera quality, and connectivity features.

## 🛠️ Tech Stack
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

## 🔍 Approach
- Data cleaning and exploratory analysis on cellphone specification data
- Feature engineering and selection
- Built and compared classification models to predict price range

## 📊 Result
Developed a classification model that accurately maps cellphone 
specifications to price range categories.

- `Cell_Phone_Price.ipynb` — Full notebook with EDA, modeling, and evaluation
